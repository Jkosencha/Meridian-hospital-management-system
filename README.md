# Meridian Hospital Management System

A role-based hospital management system built with React, Vite, and Tailwind CSS.

## Tech Stack

- React + Vite
- Tailwind CSS
- React Router

## Backend Setup

See [backend/README.md](backend/README.md) - uses `pipenv` for dependencies (not plain `venv`/`pip` anymore).
